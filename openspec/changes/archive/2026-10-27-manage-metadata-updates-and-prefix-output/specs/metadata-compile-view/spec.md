## MODIFIED Requirements

### Requirement: 编译结果查看命令

系统 SHALL 继续提供无参数 `/provider-metadata`，使用与目录刷新相同的配置与当前活动本地数据来源解析，生成私有临时文件并仅以 `[openai-api-pi-extension] <绝对路径>` 通知结果，SHALL NOT 发布模型目录、自动展示文件或写会话提示条目。新增 `check` 与 `update` 子命令 SHALL 使用 `metadata-package-updates` 定义的独立行为，不触发默认导出。文件首行 SHALL 以 `[openai-api-pi-extension]` 标识来源，其后 SHALL 包含生效配置、实际读取的数据版本、快照时间、命中分类汇总，以及每个原始公开模型 ID 的命中规则、有序具体来源链、字面候选集合、完整 canonical 身份、采用字段与来源、跳过／歧义原因和生效 overrides。生效配置 SHALL 展示 `@self` 的实际配置位置，不再展示根级或模型级布尔合并模式。

每个外部候选 SHALL 保留真实来源 ID、站点、provider、access、匹配层级和选用状态；来自统一 canonical 资料的字段 SHALL 与 provider 记录字段明确区分。即使多条候选未被选用，也 SHALL 能在文件中检查其身份和原因。固定执行链 SHALL 仅包含具体外部来源及绑定到原始公开模型 ID 的上游来源节点，不含待执行 regex、通配符或待解释关键词。上游来源 SHALL 在实际顺序位置明确标注其类型、具体模型 ID 及可提供的规范化能力字段，SHALL NOT 冒充外部候选或统一 canonical 记录；未采用的字段 SHALL NOT 被伪称为最终取值。配置区保留 `@self` / `@default` 字面写法 SHALL 不等同于固定执行链中仍有待解析关键词。

候选字符串 SHALL NOT 替换模型公开显示身份。输出 SHALL 继续脱敏凭证字段、认证头并转义外部控制字符；SHALL NOT 为展示上游来源而导出整份未经筛选的原始上游响应。

#### Scenario: 展示每个模型的编译链
- **WHEN** 用户执行无参数命令，网关有模型 `gw/claude-fable-5-1`
- **THEN** 文件首行标明插件来源，并以原始公开 ID 标识该模型，列出具体来源条目及提供字段

#### Scenario: 展示具体上游来源与顺序
- **WHEN** 模型的配置链为外部来源加 `@self`
- **THEN** 配置区保留该配置顺序，固定链在外部来源之后展示绑定到该模型原始公开 ID 的上游来源及其规范化能力字段
- **AND** 固定链不保留待解释的 `@self`，不将上游列为外部查询候选，不展示旧布尔模式

#### Scenario: 仅上游链不伪报无来源
- **WHEN** 模型链为 `["@self"]`
- **THEN** 文件展示具体上游来源节点，汇总记为外部链禁用，而不是没有执行来源或外部匹配失败

#### Scenario: 严格替换不虚构上游来源
- **WHEN** 模型生效链不含 `@self` 且外部没有可用能力数据
- **THEN** 文件保留外部未命中原因，不显示上游参与字段选择，不声称回退上游

#### Scenario: 标出 unresolved 条目
- **WHEN** 某模型的原厂或 canonical 型号无法确定
- **THEN** 文件标为 unresolved，列出具体原因；有候选时保留候选列表

#### Scenario: 配置错误时展示错误
- **WHEN** 配置存在旧版字段或根级／模型规则空链
- **THEN** 生成含插件来源、错误路径与迁移提示的诊断文件，仅临时通知带前缀路径，不发布目录或追加会话条目

#### Scenario: 不泄露凭证
- **WHEN** 用户执行该命令，原始上游响应含额外敏感字段
- **THEN** 输出与临时文件不含 API key 或认证头秘密，上游来源只展示必要的身份与能力字段，外部控制字符不会成为终端控制序列

#### Scenario: 全部 regex 候选可核对
- **WHEN** 原始模型 `proxy/Claude Fable 5.1` 匹配多个来源原始 ID
- **THEN** 文件保留原始公开 ID 并列出所有字面候选及选择原因，不只显示首个命中

#### Scenario: canonical 兜底来源明确
- **WHEN** `openai/gpt-5-codex` 的限额来自统一模型资料而非具体原厂 provider 条目
- **THEN** 文件显示完整 canonical ID，且这些字段的来源标为统一 canonical 资料

#### Scenario: 路径通知不持久化
- **WHEN** 导出成功或生成配置错误诊断文件
- **THEN** 文件保持目录 0700／文件 0600 并在返回后保留，带前缀绝对路径仅走临时通知，无新会话 JSONL 条目

#### Scenario: 更新后导出实际生效版本
- **WHEN** 新数据代次激活后执行无参数命令
- **THEN** 文件记录本次从该代次读取的版本与快照时间，不误报插件原有依赖版本或 registry 最新版本

### Requirement: 临时文件输出

无参数命令 SHALL 将编译结果写入仅当前用户可访问的临时文件（目录 0700、文件 0600，位于 `os.tmpdir()` 下），并以通知形式输出精确前缀 `[openai-api-pi-extension]`、一个空格与该文件的绝对路径。前缀 SHALL 属于通知文本而非文件路径。文件 SHALL 在命令返回后保留，由系统临时目录维护回收；系统 SHALL NOT 在关闭、退出或启动时删除这些文件，也不提供剪贴板复制或内置查看界面。配置错误同样产出带来源标识的可读诊断文件并以警告通知带前缀路径。

#### Scenario: 输出绝对路径
- **WHEN** 用户执行无参数命令且编译成功
- **THEN** 通知内容为 `[openai-api-pi-extension] <绝对路径>`，移除该前缀及空格后的完整文本是可打开的真实路径，文件保留

#### Scenario: 配置错误仍产出诊断文件
- **WHEN** 配置存在旧版字段
- **THEN** 通知以警告级别输出带前缀的诊断文件路径，文件保留

#### Scenario: 无凭证时提示
- **WHEN** 网关未配置凭证且用户执行无参数命令
- **THEN** 命令以带前缀通知提示未配置，不产生文件；`check` 与 `update` 不受网关凭证缺失限制
