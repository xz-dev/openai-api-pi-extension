# metadata-compile-view Specification

## Purpose

让用户通过一个独立命令把插件编译出的完整结果导出为临时文件，便于排查元数据问题。文件包含具体来源链、字段来源与数据版本，命令只输出绝对路径，供用户自行打开和检查。

## Requirements

### Requirement: 编译结果查看命令

系统 SHALL 继续提供 `/provider-metadata`，使用与目录刷新相同的配置与来源解析，生成私有临时文件并仅通知其绝对路径，SHALL NOT 发布模型目录、自动展示文件或写会话提示条目。文件 SHALL 包含生效配置、数据版本、快照时间、命中分类汇总，以及每个原始公开模型 ID 的命中规则、有序具体来源链、字面候选集合、完整 canonical 身份、采用字段与来源、跳过／歧义原因和生效 overrides。生效配置 SHALL 展示 `@self` 的实际配置位置，不再展示根级或模型级布尔合并模式。

每个外部候选 SHALL 保留真实来源 ID、站点、provider、access、匹配层级和选用状态；来自统一 canonical 资料的字段 SHALL 与 provider 记录字段明确区分。即使多条候选未被选用，也 SHALL 能在文件中检查其身份和原因。固定执行链 SHALL 仅包含具体外部来源及绑定到原始公开模型 ID 的上游来源节点，不含待执行 regex、通配符或待解释关键词。上游来源 SHALL 在实际顺序位置明确标注其类型、具体模型 ID 及可提供的规范化能力字段，SHALL NOT 冒充外部候选或统一 canonical 记录；未采用的字段 SHALL NOT 被伪称为最终取值。配置区保留 `@self` / `@default` 字面写法 SHALL 不等同于固定执行链中仍有待解析关键词。

候选字符串 SHALL NOT 替换模型公开显示身份。输出 SHALL 继续脱敏凭证字段、认证头并转义外部控制字符；SHALL NOT 为展示上游来源而导出整份未经筛选的原始上游响应。

#### Scenario: 展示每个模型的编译链
- **WHEN** 用户执行该命令，网关有模型 `gw/claude-fable-5-1`
- **THEN** 文件以原始公开 ID 标识该模型，列出具体来源条目及提供字段

#### Scenario: 展示具体上游来源与顺序
- **WHEN** 模型的配置链为外部来源加 `@self`
- **THEN** 配置区保留该配置顺序，固定链在外部来源之后展示绑定到该模型原始公开 ID 的上游来源及其规范化能力字段
- **AND** 固定链不保留待解释的 `@self`，不将上游列为外部查询候选，不展示旧布尔模式

#### Scenario: 仅上游链不伪报无来源
- **WHEN** 模型链为 `["@self"]`
- **THEN** 文件展示具体上游来源节点，汇总记为外部链禁用，而不是没有执行来源或外部匹配失败

#### Scenario: 严格替换不虚构上游来源
- **WHEN** 模型生效链不含 `@self` 且外部没有可用能力数据
- **THEN** 文件保留外部未命中原因，不显示上游参与字段选择，不声称回退上游

#### Scenario: 标出 unresolved 条目
- **WHEN** 某模型的原厂或 canonical 型号无法确定
- **THEN** 文件标为 unresolved，列出具体原因；有候选时保留候选列表

#### Scenario: 配置错误时展示错误
- **WHEN** 配置存在旧版字段或根级／模型规则空链
- **THEN** 生成含错误路径与迁移提示的诊断文件，仅临时通知其路径，不发布目录或追加会话条目

#### Scenario: 不泄露凭证
- **WHEN** 用户执行该命令，原始上游响应含额外敏感字段
- **THEN** 输出与临时文件不含 API key 或认证头秘密，上游来源只展示必要的身份与能力字段，外部控制字符不会成为终端控制序列

#### Scenario: 全部 regex 候选可核对
- **WHEN** 原始模型 `proxy/Claude Fable 5.1` 匹配多个来源原始 ID
- **THEN** 文件保留原始公开 ID 并列出所有字面候选及选择原因，不只显示首个命中

#### Scenario: canonical 兜底来源明确
- **WHEN** `openai/gpt-5-codex` 的限额来自统一模型资料而非具体原厂 provider 条目
- **THEN** 文件显示完整 canonical ID，且这些字段的来源标为统一 canonical 资料

#### Scenario: 路径通知不持久化
- **WHEN** 导出成功或生成配置错误诊断文件
- **THEN** 文件保持目录 0700／文件 0600 并在返回后保留，绝对路径仅走临时通知，无新会话 JSONL 条目

### Requirement: 临时文件输出

命令 SHALL 将编译结果写入仅当前用户可访问的临时文件（目录 0700、文件 0600，位于 `os.tmpdir()` 下），并以通知形式输出该文件的绝对路径。文件 SHALL 在命令返回后保留，由系统临时目录维护回收；系统 SHALL NOT 在关闭、退出或启动时删除这些文件，也不提供剪贴板复制或内置查看界面。配置错误同样产出可读诊断文件并以警告通知其路径。

#### Scenario: 输出绝对路径
- **WHEN** 用户执行该命令且编译成功
- **THEN** 通知内容为该临时文件的绝对路径，文件保留

#### Scenario: 配置错误仍产出诊断文件
- **WHEN** 配置存在旧版字段
- **THEN** 通知以警告级别输出诊断文件路径，文件保留

#### Scenario: 无凭证时提示
- **WHEN** 网关未配置凭证
- **THEN** 命令提示未配置，不产生文件
